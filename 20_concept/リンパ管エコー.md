# リンパ管エコー

## 定義

トレーサーを使わずに集合リンパ管の形態を直接描出する超音波検査。LVAの術前マッピングと変性度評価に使う。ICGリンパ管造影が「トレーサーの届いた管」しか映さないのに対し、エコーは管そのものを見るため、進行例でも残存リンパ管を捉えうる。変性度は NECST分類（normal / ectasis / contraction / sclerosis）で表し、LVAの効果が最も高いのは ectasis型とされる。

## このvaultでの知見

- **ワークフローの実測値**（24例41肢、83吻合）: 術前エコー**平均26.4分**（16〜48分）、術中の静脈同定**2分10秒**、リンパ管同定**8分5秒**。**83箇所すべてで術前予測どおりに同定できた**（[[@hara_PlastReconstrSurgGlobOpen_2026 リンパ管エコーによるLVA術前計画の所要時間と術中同定時間を24例41肢で定量化したワークフロー分析|Hara 2026]]）。
- **病期が進むほど同定に時間がかかる。** ISL stage 1で4分53秒 → stage 3で9分35秒（p = 0.039、1 vs 3 で p = 0.0014）。線維化の程度でも同じ向きの傾向（高度で11分48秒）だが有意差なし（p = 0.082）（[[@hara_PlastReconstrSurgGlobOpen_2026 リンパ管エコーによるLVA術前計画の所要時間と術中同定時間を24例41肢で定量化したワークフロー分析|Hara 2026]]）。
- **D-CUPS基準** — リンパ管と静脈の鑑別基準（Doppler陰性・Crossing＝交差・Uncollapsible＝非圧縮性・Parallel＝並走・Superficial fascia＝浅筋膜直下）。27例44肢98切開での感度は**ドプラ陰性・交差・浅筋膜直下が各100%**、非圧縮性68.4%、並走19.4%（[[@hara_PlastReconstrSurgGlobOpen_2026 リンパ管エコーによるLVA術前計画の所要時間と術中同定時間を24例41肢で定量化したワークフロー分析|Hara 2026]] のレビュー部分）。
- **走査位置の目安**: 大腿では伏在大腿接合部の5cm遠位で**大伏在静脈の外側17.3mm**、下腿では膝窩の5cm遠位で**内側12.6mm**。リンパ管は浅筋膜の直下（第1〜2層）を走る（[[@hara_PlastReconstrSurgGlobOpen_2026 リンパ管エコーによるLVA術前計画の所要時間と術中同定時間を24例41肢で定量化したワークフロー分析|Hara 2026]]）。
- **重症例では外側を探す。** 内側での検出率は病期が進むと下がるが、**外側下腿では stage 2b・3で100%** に達する（[[@hara_PlastReconstrSurgGlobOpen_2026 リンパ管エコーによるLVA術前計画の所要時間と術中同定時間を24例41肢で定量化したワークフロー分析|Hara 2026]]）。
- **プローブ選択**: 表層5mm以内なら24〜33MHz、大半の症例では**12〜18MHzが最もバランスがよい**。50MHz以上は減衰のため浅筋膜直下でも届きにくい（[[@hara_PlastReconstrSurgGlobOpen_2026 リンパ管エコーによるLVA術前計画の所要時間と術中同定時間を24例41肢で定量化したワークフロー分析|Hara 2026]]）。

## 論点

**「見つけられる」ことと「効く」ことは別である。** [[@hara_PlastReconstrSurgGlobOpen_2026 リンパ管エコーによるLVA術前計画の所要時間と術中同定時間を24例41肢で定量化したワークフロー分析|Hara 2026]] はタイトルに Works と掲げているが、測ったのは所要時間であって術後の浮腫改善ではない。対照群もなく、ICG併用の有無という近似的比較も37.5%しかICGを受けておらず p = 0.077 にとどまる。**エコー導入の根拠として引用するなら、「段取りが立つ」までであって「成績が良くなる」ではない。**

もうひとつの論点は**検者依存性**である。本研究では執刀医自身がエコーを行っており、三次元的な位置関係の把握という点では有利だが、再現性の面では最も不利な設計でもある。放射線科医や技師でも所見を共有できれば可能だと著者らは述べているが、検証されていない。D-CUPS基準のうち**当てになるのは3項目だけ**（ドプラ陰性・交差・浅筋膜直下）という知見は、この検者依存性を下げる方向に効く。
