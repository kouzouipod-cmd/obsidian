# Cordeiro分類

## 定義

上顎切除欠損の分類。**切除範囲の段階**で type I〜IV に分ける。[[@cordeiro_PlastReconstrSurg_2000 上顎切除・中顔面欠損の分類システムと再建アルゴリズムを60皮弁の経験から提唱した原典|Cordeiro PG 2000]] が原典。[[Brown分類]] と並ぶ双璧だが採用頻度は低い。

- **type I** 限局性上顎切除
- **type II** 亜全摘
- **type IIIa** 全摘・眼窩内容温存
- **type IIIb** 全摘・眼窩内容除去
- **type IV** 眼窩上顎切除

## このvaultでの知見

- 原典は60皮弁の経験から分類とアルゴリズムを同時に提唱した。内訳は type I 7・II 10・IIIa 13・IIIb 18・IV 10（[[@cordeiro_PlastReconstrSurg_2000 上顎切除・中顔面欠損の分類システムと再建アルゴリズムを60皮弁の経験から提唱した原典|Cordeiro PG 2000]]）。
- **眼球を残すか除くかで IIIa と IIIb を分ける**のがこの分類の要。眼窩底を支持する必要があるか、補綴を収める空洞を作るかで再建の目標が正反対になるため（[[眼窩底再建]] 参照）。
- ムーコル症後の上顎欠損50例で、IIA / IIB / IIIA / IIIB / IV に層別して皮弁を使い分けた（[[@vashistha_JStomatolOralMaxillofacSurg_2024 COVID-19関連ムーコル症後の上顎切除欠損50例に対する遅延再建の安全性と整容成績を検討した前向き観察研究|Vashistha A 2024]]）。
- **同一術者の15年・100皮弁でCordeiro分類の運用実績が示されている。** 欠損はType I 20・IIA 8・IIB 8・IIIA 22・IIIB 23・IV 19。遊離皮弁94%、生着100%（部分喪失1例）、30日死亡4.2%（[[@cordeiro_PlastReconstrSurg_2012a 1992-2006年の単一術者による上顎・中顔面再建100皮弁のアルゴリズムと成績を示した15年間の総括（第1報）|Cordeiro PG 2012]]）。技術の改良と成績の推移は第2報（[[@cordeiro_PlastReconstrSurg_2012 上顎・中顔面再建100皮弁の前半50と後半50を比較し発語・食事・外反・整容の改善を示した技術改良の総括（第2報）|Cordeiro PG 2012]]）。
- ⚠️ **[[@cordeiro_PlastReconstrSurg_2000 上顎切除・中顔面欠損の分類システムと再建アルゴリズムを60皮弁の経験から提唱した原典|Cordeiro PG 2000]] と症例が重複する。** 第2報の前半50皮弁の3つの数値（無制限食44.4%・発語正常38.9%・外反71.4%）が2000年報告の数値と完全に一致する。独立した症例集積として数えない。
- **腓骨による上顎再建（85皮弁・73例）の欠損は type 2 が大半**（[[@cho_PlastReconstrSurg_2024 腓骨皮弁による上顎再建85皮弁73例の15年間の経験でインプラント95.9%・皮弁全喪失2.7%を示した後方視的研究|Cho MJ 2024]]）。

## 論点

**Brown分類との軸の違いを理解して使い分ける。** Cordeiroは切除範囲の段階という一次元、Brownは垂直class×水平subclassの二軸。歯槽・口蓋の欠損幅を表現できるのはBrownで、眼窩内容の扱いを明示するのはCordeiro。**どちらを採用するかで研究の群分けが変わる。**

異なる分類を使う研究を統合する際は、どちらかに変換するか両方を併記すること。本ライブラリでは [[@vashistha_JStomatolOralMaxillofacSurg_2024 COVID-19関連ムーコル症後の上顎切除欠損50例に対する遅延再建の安全性と整容成績を検討した前向き観察研究|Vashistha A 2024]] がCordeiro、[[@rogers_EurArchOtorhinolaryngol_2022 上顎癌切除後の再建法と口腔リハビリテーションの27年間の変遷を186例で追跡し頬骨インプラントによる転換を示した後方視的コホート|Rogers SN 2022]] がBrownを使っており、直接比較できない。

**Cordeiro分類の文献は、同一の症例群が複数回報告されている点に注意する。** 2000年・2012年（第1報・第2報）の3本は、同じ術者・同じ施設・重なる期間の系列である。統合したり数えたりするときは、1つの症例群の報告として扱う。
