# 再建プレート合併症

## 定義

顎骨再建に用いる金属プレートに起因する合併症。露出、破折、脱転が主。長期経過で顕在化する。

## このvaultでの知見

- 下顎205例（[[@chang_Microsurgery_2022 下顎再建における骨皮弁（腓骨）と軟部皮弁（ALT）＋再建プレートのプレート関連合併症とQOLを205例で比較した後方視的研究|Chang TY 2022]]）:
    - プレート関連合併症: ALT＋再建プレート 37.9% / 腓骨＋再建プレート 25.6% / 腓骨＋ミニプレート 13.1%（p=0.0079）
    - プレート露出: 24.1% / 15.7% / 4.9%（p=0.0128）
    - 破折・脱転: 24.1% / 9.3% / 9.8%（p=0.023）
- 悪化因子: [[放射線性骨壊死]]（HR 6.19）、術後放射線治療（HR 2.87）
- プレート関連合併症は疼痛スコアを介し [[術後QOL]] を有意に低下させる（β=-0.56、p=0.034）。

## 論点

結論は明快 — **再建プレートを避け、腓骨皮弁＋ミニプレートを選ぶ。** 特に骨壊死例・術後照射例。ただしこれは下顎のデータであり、上顎での検証は乏しい。
