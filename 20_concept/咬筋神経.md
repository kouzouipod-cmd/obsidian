# 咬筋神経

## 定義

三叉神経下顎枝の前区から分岐する最大の運動枝で、咬筋を支配する。[[顔面神経再建]] における主要なドナー神経。咬筋が複数枝で重複支配されているため、採取しても機能欠損は軽微。

## このvaultでの知見

出典は [[@stigger_JPRASOpen_2026 顔面神経再建における咬筋神経の同定法を14側の屍体解剖から3つのランドマークで定量化し図解と術中ビデオで手順化した解剖研究|Stigger 2026]]（10体の遺体・14側の実測）。

### 位置（術前マーキングに使える3点）

| 基準 | 距離 |
|---|---|
| 耳珠頂点からの前方 | **3.89 ± 0.27 cm**（実務では約4cm） |
| 頬骨弓下縁からの下方 | **1.01 ± 0.18 cm**（実務では約1cm） |
| SMASからの深さ | **1.11 ± 0.21 cm** |

- **男女差はいずれも有意でない**（p=0.897 / 1.000 / 0.197、Mann-Whitney U）。性別で補正する必要はない。
- **全標本で顔面神経前頭枝に近接**し、その直下またはやや前後に位置した。

### 同定の手順

フェイスリフト型切開 → sub-SMAS層で顔面神経枝を同定 → 咬筋上部の線維を頬骨弓から剥離 → Langenbeck鈎2本で筋線維を鈍的に縦割 → 神経刺激装置で確認。下顎切痕の触知も補助になる。

**神経刺激装置が前提のため、筋弛緩薬を使わない麻酔計画が必要。** 麻酔科との事前調整が要る。

## 論点

**顔面神経前頭枝の近接は、道標であると同時にリスクでもある。** 前頭枝麻痺は整容的に目立つため、この実測値は「咬筋神経を探す」だけでなく「前頭枝を避ける」ためにも読むべき。

計測は屍体・14側であり、生体での軟部組織の可動性や体位による差は検証されていない。数値はあくまで目安として扱う。
