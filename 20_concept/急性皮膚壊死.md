# 急性皮膚壊死

## 定義

皮膚が突然壊疽性に変化する病態の総称。原因が多岐にわたり、罹病率・死亡率ともに高い。形成外科が最初に相談を受ける入口になりやすい — 抗リン脂質抗体症候群では**患者の約40%が皮膚症状を最初の徴候として受診する**（[[@difrancesco_AnnPlastSurg_2003 APS患者の約40%が皮膚症状で初発すると指摘し広範な皮膚壊死に形成外科的介入を要した1例を提示した症例報告とレビュー|DiFrancesco LM 2003]]）。

## このvaultでの知見

- **鑑別は12ある**（[[@karimi_JCutanMedSurg_2017 急性皮膚壊死の12の原因を鑑別として整理し早期診断と治療の手引きにまとめた総説|Karimi K 2017]]）: **ワルファリン起因性皮膚壊死・ヘパリン起因性皮膚壊死・カルシフィラキシス・壊疽性膿皮症・塞栓症・電撃性紫斑病・ドクイトグモ咬傷・壊死性筋膜炎・エクチマ壊疽・抗リン脂質抗体症候群・高ガンマグロブリン血症・クリオグロブリン血症。**
- ⚠️ **抗凝固薬自体が原因になりうる。** ワルファリンとヘパリンの両方が上のリストに載っている。APS患者は抗凝固薬を使っているため、**壊死の原因が疾患か治療薬かという問いが必然的に生じる。**
- **3つが併存した実例。** 乳房壊死をワルファリン起因性と診断して乳房切除＋分層植皮を行ったが、3週間後の再燃時に**ヘパリン起因性血小板減少症とAPSの両方**が判明した（[[@dutton_PlastReconstrSurg_2013 乳房壊死をワルファリン起因性と診断して乳房切除と植皮を行ったが後にHITとAPSの併存が判明し死亡した症例報告|Dutton JW 2013]]）。MeSHに Fatal Outcome・Heart Arrest。
- **外見や分布では決められない。** 両耳介の黒色壊死はレバミゾール混入コカインに典型的とされるが、**ワルファリン中止で再燃した**ことから抗リン脂質抗体が原因と判断された例がある（[[@edrees_JClinRheumatol_2011 両上腕と両耳介の黒色壊死で発症しワルファリン中止により再燃したことでコカインより抗リン脂質抗体を支持した症例報告|Edrees A 2011]]）。
- **手術と保存的治療の両方に成功例がある。** 広範な植皮を要した例（[[@abernethy_JRheumatol_1995 APSの最初の徴候として広範な皮膚壊死を急性発症しステロイドと抗凝固で治療後に広範な植皮を要した症例と6例のレビュー|Abernethy ML 1995]]）、免疫抑制下でのみ自家植皮が生着した例（[[@fiehn_AnnRheumDis_2001 二次性APSによる両下肢の広範な皮膚筋壊死に自家植皮を行い免疫抑制下でのみ生着したことを示した症例報告|Fiehn C 2001]]）、**手背の全層壊死を84日の保存的治療で治し手の機能も戻した例**（[[@niu_AdvSkinWoundCare_2020 劇症型APSによる右手背の全層皮膚壊死を多職種チームによる84日間の保存的創傷管理で治癒させ手の機能も回復した症例報告|Niu N 2020]]）。
- **全身が崩れていれば創の話は成り立たない。** 脳静脈洞血栓症・肺胞出血・腎血栓性微小血管症・前腕壊死を同時に発症し死亡した劇症型の例（[[@kyoung_JWoundCare_2024 21歳女性が脳静脈洞血栓症と肺胞出血と腎血栓性微小血管症と前腕壊死性創を同時発症し劇症型APSで死亡した症例報告とレビュー|Kyoung J 2024]]）。

## 論点

**「切るべき壊死」と「切ってはいけない壊死」が同じ見た目をしうる。** 12の鑑別のうち**壊死性筋膜炎だけが緊急のデブリードマンを要し**、他の多くは内科的管理が先に来る。にもかかわらず所見からの鑑別は難しく、[[@dutton_PlastReconstrSurg_2013 乳房壊死をワルファリン起因性と診断して乳房切除と植皮を行ったが後にHITとAPSの併存が判明し死亡した症例報告|Dutton JW 2013]] では5つの根拠が揃ったことで鑑別が止まり、結果として3つの病態を見落とした。**鑑別表は覚えるためではなく、一つに決めつけないために使う。**

**順序が成績を決める。** [[@difrancesco_AnnPlastSurg_2003 APS患者の約40%が皮膚症状で初発すると指摘し広範な皮膚壊死に形成外科的介入を要した1例を提示した症例報告とレビュー|DiFrancesco LM 2003]] は「内科的に安定してから形成外科的介入」と書き、[[@fiehn_AnnRheumDis_2001 二次性APSによる両下肢の広範な皮膚筋壊死に自家植皮を行い免疫抑制下でのみ生着したことを示した症例報告|Fiehn C 2001]] は自家植皮が**グルココルチコイドとシクロスポリンAによる免疫抑制下でのみ成功した**と報告している。**植皮の生着は局所の問題ではなく全身の病勢の問題である。** 逆に順序を誤ると、[[@dutton_PlastReconstrSurg_2013 乳房壊死をワルファリン起因性と診断して乳房切除と植皮を行ったが後にHITとAPSの併存が判明し死亡した症例報告|Dutton JW 2013]] のように侵襲だけが積み上がる。

**そもそも切らない選択がある。** [[@niu_AdvSkinWoundCare_2020 劇症型APSによる右手背の全層皮膚壊死を多職種チームによる84日間の保存的創傷管理で治癒させ手の機能も回復した症例報告|Niu N 2020]] は手背の全層壊死を84日かけて保存的に治し、機能まで戻した。通常なら植皮か皮弁の適応である。劇症型では手術侵襲そのものが血栓の誘因になりうることを考えると、**「切らない」には合理性がある。** ただし1例であり、部位・年齢・全身状態に依存する。**期間を許容できるかどうかが実際の分かれ目。**

**この領域の主張は1995年から本質的に変わっていない。** 「早期認識が壊死の範囲を限定する」という結論は [[@abernethy_JRheumatol_1995 APSの最初の徴候として広範な皮膚壊死を急性発症しステロイドと抗凝固で治療後に広範な植皮を要した症例と6例のレビュー|Abernethy ML 1995]]（1995年）も [[@difrancesco_AnnPlastSurg_2003 APS患者の約40%が皮膚症状で初発すると指摘し広範な皮膚壊死に形成外科的介入を要した1例を提示した症例報告とレビュー|DiFrancesco LM 2003]]（2003年）も [[@karimi_JCutanMedSurg_2017 急性皮膚壊死の12の原因を鑑別として整理し早期診断と治療の手引きにまとめた総説|Karimi K 2017]]（2017年）も同じことを述べている。**30年で症例数は増えたが、方針の根拠は増えていない。**
