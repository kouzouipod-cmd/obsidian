# ハファデイ英会話（グアム旅行の英会話アプリ）

グアム旅行のための英会話学習アプリ。実体は `index.html` の1ファイルで、
Claude の Artifact として公開してある。

- 公開URL: https://claude.ai/code/artifact/062de675-4d93-4ced-836f-e7c49cbbfe9a
- ソース: `99_app/guam_travel_english/index.html`

## 中身

| 画面 | 内容 |
|---|---|
| フレーズ | 200フレーズを旅の順番（機内→入国審査→ホテル→移動→レストラン→カフェ→買い物→支払い→ビーチ→トラブル→ひとこと→帰国）で12場面に。英語・日本語・つながった音のカタカナ・発音再生・☆（覚えた印） |
| 会話を通す | 入国審査／夕食／シャトル／シュノーケル／部屋の不具合／ABCストア／カフェ／道を聞く／帰りのチェックイン、の9場面を通しで再生。相手のセリフも入っている |
| 聞き取りクイズ | 5種類（聞き取り・日本語から英語・穴うめ・語順・こう言われたら）。8/12/16問、場面しぼり可。間違えたフレーズは次回に出やすくなる |
| 言いたいことを英語に | 日本語を書くと、現地で通じる英文と読み方が返る（Claudeへ問い合わせ） |

## 覚えておくこと

- ☆と成績は artifact の `db` に保存。同じアカウントならスマホでも同じ記録が出る。
  `db` が使えないときは端末の localStorage に落ちる。
- 発音は端末の音声合成（Web Speech API）。ツールバーの「音が出ないとき」に
  声の選択・テスト再生・状態表示（鳴っている／音が返ってこない／ブラウザが止めている等）がある。
  再生は cancel の直後に speak すると無音になる端末があるため90ms待ってから呼び、
  1.6秒たっても onstart が来なければ「音が返ってこない」と表示する。
  英語の声が1つも無い端末では聞き取り問題を出さない。
- 場面ごとの「メモ」（チップの相場、リゾートフィー、リーフの流れ、911 など）は
  `SCENES` 配列の `tip` にある。中身を直すならそこ。
- フレーズを足すときは `RAW` 配列に `[場面id, 英語, 日本語, カタカナ, 1=自分/0=相手]` を1行足すだけ。
  IDは「場面id＋英文」から作る固定値なので、行を並べ替えても☆の記録はずれない
  （旧版の `p0`〜`p118` は `migrateKeys` が読み替える。この対応表は先頭119行の順番に依存するので、
  **先頭119行だけは並べ替えない**）。
- クイズの「こう言われたら」は `DIALOGUES` から自動生成される。相手のセリフの次の行が
  `you` になっている箇所がそのまま問題になるので、会話を足せば出題も増える。

このノートは論文ノートではないので、citekey も frontmatter の `domain` も付けない。
